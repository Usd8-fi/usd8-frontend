保険

USD8は、USD8の利用履歴に基づく保険スコアに応じて、DeFiユーザーに無料の保険を提供します。対象は、私たちのチームと第三者のセキュリティパートナーが審査したさまざまなDeFiトークンです。USD8を使えば使うほど、補償は手厚くなります。保険対象のDeFiトークンが大きく下落した場合（現在の基準は20%）、ユーザーは価値の最大80%を請求できます。

実際の支払額は、他の請求者と比べたそのユーザーのUSD8利用履歴と、カバープールの規模によって決まります。

支払いの原資は、USD8のカバープールです。カバープールは資産の種類ごとに分かれた公開ボールトで、USD8のトレジャリー収益がインセンティブとして支払われます。カバープールに預け入れたLPは誰でもUSD8建てのステーブルコイン利回りを得られますが、プール内の資産は損失の補償に使われる可能性があります。

この保険の仕組みが画期的なのは、次の2点です。

  1. 業界初の補償であり、過去・現在を問わず、すべてのUSD8ユーザーが無料で利用できます。
  2. wBTCや、AAVE、LINK、UNIといったアルトコインなど、これまで利回りの源泉が乏しかった資産に、ステーブルコイン建ての新たな利回りをもたらし、資本効率を高めます。

ユーザーが請求を行うと、USD8の手元にはハッキングされたLPトークンが大量に残ります。そのためUSD8は、これらの資金を回収することに大きな経済的インセンティブを持つ、独自の立場に立つことになります。ブラックハットが得をする今の暗号資産の世界とは逆に、USD8はホワイトハット・エコノミーを育てていきます。そこでは一般の人々も、失われた資金の追跡と回収に参加します。詳しくはホワイトハット・エコノミーのページをご覧ください。

この仕組みは、善良な参加者に大きなインセンティブを与え、悪意ある者には抑止となる負担を課すことで、健全な文化を育てられる可能性があります。そしてそれが業界全体の共通認識として根づけば、悪意ある行為はさらに減っていくはずです。自らの不正のせいで、一般の人々や専門家から永遠に追われ続けるとわかっていれば、ハッカーも犯行に及ぶその瞬間に、ハッキングや窃盗を思いとどまるかもしれません。

DeFi保険

  • USD8とsUSD8を保有していると、ブロックごとに保険スコアが貯まります
  • 保険スコアを使って、USD8やsUSD8を含むさまざまな保険対象DeFiトークンの保険金を請求できます
  • スコアが高いほど支払額も増えます。上限は価値の80%で、さらにカバープールの上限による制限があります
  • スコアは譲渡できず、失効もしません
  • 支払いの原資はカバープールです

例：Aave aUSDCが、最大補償率80%の保険対象トークンだとします

  1. aUSDCのUSDCに対する価格が1から0.3に下落
  2. 保険スコアを持つユーザーは、手持ちのaUSDCと引き換えに、カバープールの資産から最大0.8 USDC相当を受け取れます

請求プロセス

請求は、オンチェーンとオフチェーン（TEE）の処理を組み合わせた3つのステップで進みます。完了までの期間は、ベータ期間中が約9〜12日、ベータ終了後は約6〜9日です。各ステップの期限を逃さないようご注意ください。

ステップ1：請求の提出

次の条件をすべて満たせば、誰でも請求を提出できます。

  1. 保険対象トークンの連続する24時間TWAP価格を比べて、過去1〜6日の間に20%を超える下落がある
  2. 価格下落の7日以上前に獲得した、未使用の保険スコアを持っている
  3. 価格下落の7日以上前から、その保険対象トークンを保有している

請求には10 USD8の保証金（ボンド）も必要ですが、条件2と3を満たしていれば全額返金されます。価格がいつ下落したかを申告する必要はありません。下落はTEEが自動で検出し、正確なブロックまで特定します。

重要：請求の受付は、最初の有効な請求から3日後に締め切られます。それ以降、その保険対象トークンについて請求は提出できません。

ステップ2：請求の精算

請求の精算は誰でも実行できます。TEEのアテステーションを提出するだけです。TEEはオープンソースのアルゴリズムで全請求者の保険スコアと支払額を計算するため、結果は誰でも完全に検証できます。

各請求者の支払額は、次の3つをもとに計算されます。

  1. 全請求者の合計スコアに占める、その請求者の保険スコア
  2. カバープールの上限
  3. 保険対象トークンの最大補償率

例：請求者はAとBの2人で、Aのスコアは100、Bは200です。2人とも、最大補償率80%の保険対象トークンを500ドル分ずつエスクローに預けています。カバープールには現在2250ドル相当の資産があります。

  1. カバープールの上限は現在50%なので、使えるのは合計1125ドルです。その80%にあたる900ドルが請求に充てる予算になります。AのスコアはBの半分なので、請求できる上限はAが300ドル、Bが600ドルです
  2. 一方、2人とも500ドル分の保険対象トークンを預けており、最大補償率は80%なので、損失に対する請求額の上限はそれぞれ400ドルです
  3. 結果として、Aには300ドル、Bには400ドルが支払われます

精算の受付期間は最長3日間で、精算が済めばすぐに支払いを確定できます。期間内に精算されなかった場合は、エスクローに預けたトークンを引き出せます。この場合、保険スコアは使用されません。

ベータ期間中は、精算後さらに3日間、管理者がTEE署名付きの新しい精算結果を提出して検証・異議申し立てを行えます。悪意のある精算やバグが紛れ込まないようにするための安全措置です。

ステップ3：支払いの確定

このステップでは、請求者は3日以内に支払いを受け取るかどうかを選べます。受け取る場合は、

  1. エスクローに預けた保険対象トークンと保険スコアを手放し、
  2. 受け取る権利のある支払額と同じUSD価値のカバープール資産を受け取ります

受け取らない場合は、エスクローに預けたトークンを引き出し、保険スコアもそのまま残せます。

支払いを確定するかどうかにかかわらず、保証金の条件を満たしていれば保証金は返還されます。

重要：支払いの受付期間は3日間です。期間を過ぎると、未処理の請求はすべて「受け取らなかった」ものとして扱われ、エスクローに預けたトークンを引き出せるようになります。

TEE

USD8は、オープンソースのアルゴリズムを実行するAmazonのセキュアエンクレーブをオフチェーンで使い、支払額の計算と署名を行います。TEEは誰でも起動でき、その結果をオンチェーンに提出できます。オンチェーン側はTEEの署名を検証してから最終結果を受け入れます。アルゴリズムがオープンソースなので、結果は誰でも検証できます。

将来的には、ウォークアウェイテストをクリアするため、Brevisのようなzkコプロセッサネットワークへ移行する計画です。

ブースター



ブースターは、請求の提出時に追加できるNFTで、1つにつき保険スコアの合計を1%押し上げます。対象となるブースターは支払いを受け取る際にバーンされ、それ以外は返却されます。複数のブースターを重ねて使うこともできます。ブースターは販売しておらず、USD8の成長に貢献してくれた初期ユーザーにのみミントされます。最新情報はXとTelegramでお知らせしています。

Ethereumアドレスを入力すると、保有しているブースターを確認できます

カバープール

カバープールは、誰でもいつでも預け入れ・引き出しができる公開ボールトです。各カバープールには次の特徴があります。

  • 特定のトークン（例：wstETH）を預け入れ資産として受け付ける
  • USD8のトレジャリー利回りを原資に、USD8建てで利回りを支払う
  • 規模に上限がある
警告：保険対象トークンのいずれかで20%以上の価格下落が起きた場合、カバープールの資産は請求の支払いに使われます。

保険対象トークン

保険対象トークンは慎重な評価を経て選定され、その後も継続的に見直されています。USD8が認めている独立したセキュリティ監査・認証は、次の機関によるものです。

  • OpenZeppelin
  • Trail of Bits
  • Consensys Diligence
  • Security AllianceのSEAL認証

引き出し

引き出しには7日間のクールダウン期間があります。進行中の請求がなければ、いつでもリクエストできます。

クールダウン中に新たな請求が発生した場合、インシデントが解決するまで引き出し手続きは一時停止します。解決までには、最初の請求から数えてベータ期間中はさらに9〜12日（ベータ終了後は6〜9日）かかることがあります。その間も、クールダウン中の資産はすべて保険金の支払いに充てられる対象です。

クールダウン中の資産は利回りを生まず、引き続き請求の補償に充てられます。クールダウンが終わった資産はいつでも引き出せ、その時点からは請求の補償に使われることも、利回りが付くこともありません。

保険金の支払い上限

1回のインシデントでカバープールから支払える総額には上限があり、現在は50%に設定されています。つまり、各インシデントの支払額は、その時点のカバープールの規模の50%までです。

ホワイトハット・エコノミー

ホワイトハット・エコノミーは、USD8における「執行」のレイヤーです。失われた資産を取り戻し、DeFiで今後起こりうる悪意ある行為を抑止するうえで、重要な役割を担います。

請求が成立すると、手放された保険対象トークンはUSD8プロトコルのものとなり、ホワイトハット・エコノミーを動かす資金源になります。ハッキングの規模に応じて、次のような複数の仕組みを検討していきます。

  • トークン化された不良債権市場
  • バウンティと匿名での情報提供
  • ホワイトハット・ギルドとオープンな教育
  • 法的措置と法執行機関との連携

なぜ重要なのか

保険だけでは、あくまで事後の対応にとどまります。カバープールはハッキング後にユーザーの損失を補てんしますが、そもそもハッキングを生んだインセンティブを変えるわけではありません。

ホワイトハット・エコノミーは、USD8の構想のもう半分です。請求のたびに得られる資産を攻撃者への圧力に変え、一般の人々一人ひとりを、悪意ある者にとっての潜在的な敵に変えていきます。

これが、思想的ルーツで述べた根深い問題、つまり暗号資産の世界で悪意ある行為がはびこる原因となった「インセンティブの整合と執行のレイヤーの欠如」に対する、USD8の答えです。善良な参加者に報い、悪意ある者には恒久的に積み重なるリスクを課すことで、ホワイトハット・エコノミーは業界のインセンティブを整え直し、時間をかけて次のハッキングそのものを思いとどまらせていきます。

USD8が手放された保険対象トークンを相応の量保有した段階で、ホワイトハット・エコノミーのローンチを目指します。

よくある質問

USD8やsUSD8を持つだけで、無料で保険が付くのですか？

はい。それが他のステーブルコインにはないUSD8のメリットです。保険スコアはブロックごとに貯まり、USD8/sUSD8を多く、長く保有するほど多くのスコアを獲得できます。

スコアの貯まり方は資産によって異なり、現在は1 USD8につき1日1スコア、1 sUSD8につき1日0.1スコアです。

保険金はどこから支払われるのですか？

保険金はカバープールから支払われます。カバープールは、誰でも預け入れができるオープンなトークンボールトで、現在はwstETHのプールとUSD8のプールの2つがあります。

預け入れた人には、USD8のトレジャリー利回りを原資とする高い年利が支払われます。その代わり、保険対象トークンが原資産に対して20%を超えて下落した場合は、預け入れた資産が請求の支払いに使われることがあり、1回のインシデントで各カバープールの残高の最大50%が使われる可能性があります。まさにハイリスク・ハイリターンです。

保険スコアはいつから請求に使えますか？

保険スコアは獲得から7日後に利用可能になります。請求に使えるのは、この利用可能なスコアだけです。

以前はUSD8を持っていましたが、今は持っていません。それでも保険の対象ですか？

はい。これまでに貯まった保険スコアがあるはずで、スコアは失効しません。獲得から7日以上経ったスコアがあれば、請求できます。

支払額はどのくらいになりますか？

支払額は、（1）同じ時期に請求している他の人と比べたあなたの保険スコアと、（2）カバープールの規模による上限、の2つで決まります。

保険スコアが多いほど、請求におけるウェイトが大きくなります。支払額の上限は80%で、スコアが少ないとそれを下回ることもあります。ただし、最終的な支払額が低すぎると感じたら、受け取らずに保険スコアを今後のために残すことがいつでもできます。

請求には何が必要ですか？

  • 請求の対象となる保険対象トークン
  • 保険スコア
  • 10 USD8の保証金（請求の対象と認められた場合、請求後に返金）
  • ブースター（任意）

カバープールLPのリスクをどう抑えていますか？

カバープールの資産は請求の支払いに使われることがあるため、リスクが高く、その分年利も高めです。カバープールのリスクを抑えるため、私たちのチームは次のことを行っています。

  • 保険を提供する前に、すべてのプロトコルを独自に審査する
  • 各プロトコルの第三者監査を確認する
  • 継続的なモニタリングに基づき、プロトコルごとの補償を調整・取り消しする

請求が頻繁に起きることは想定していませんが、その可能性は常にあります。

ベータ版では何が違いますか？

ベータ版には、安全のための「補助輪」がいくつか付いており、ベータ終了後に外す予定です。ベータ期間中は、管理者とタイムロックに特別な権限があります。

  • 管理者またはタイムロックは、新しい精算ルートを提出して、インシデントの支払いに関する精算に異議を申し立てられます。そのため請求プロセスに3日間の異議申し立て期間が加わりますが、これはベータ終了後に廃止されます。
  • タイムロックはRegistry、USD8、Treasury、DefiInsuranceをアップグレードできます。このアップグレード機能はベータ終了後に廃止する予定です。

USD8にガバナンストークンはありますか？

現時点ではありません。

USD8に関わるリスクをすべて教えてください。

もちろんです。透明性のページにまとめています。

USD8はどうやって収益を得ていますか？

USD8の収益源は次のとおりです。

  • USD8のトレジャリー利回りの一部
  • 支払いの残り20%：請求者が受け取れる補償は最大80%なので、残る20%がUSD8の手数料になります
  • ホワイトハット・エコノミーを通じて回収した損失の一部

USD8に貢献するにはどうすればよいですか？

メカニズム設計、パートナーシップ、マーケティングなど、幅広い分野でコミュニティからの貢献を歓迎しています。提案や批判、アイデアがあれば、usd8-coreリポジトリでissueを作成するか、Telegramグループでチームと議論してください。貢献してくれた方はブースターを獲得できます。

USD8を開発しているのは誰ですか？

USD8を開発しているのは@codephobicです。トップクラスのDeFiプロトコルやL2の監査に7年以上携わってきたセキュリティリサーチャーです。

このページでは、USD8プロトコルにおける信頼の前提とリスクを説明します。多くはDeFiプロトコルに共通するものですが、私たちはそれを事前にユーザーへ明示することにしました。

管理者とタイムロック

管理者の権限は設計段階でできる限り絞り込み、重要な操作のほとんどはタイムロックを通じて実行します。これにより、ユーザーは予定されている変更に対応する時間を確保できます。

管理者が行えるシステム設定は次のとおりです。

  • USD8トレジャリーの資金を事前承認済みの戦略に配分する（戦略を直接追加することはできません）
  • 一時停止、収益の配分比率、プロトコル手数料、カバープールの預け入れ上限を管理する

タイムロックは、より重要なシステム設定を管理します。

  • 管理者の追加・削除、またはタイムロック自体の置き換え
  • プール、保険対象トークン、スコアリング、オラクル、インシデント・引き出しのタイミング、請求の保証金、TEE署名者の設定
  • Treasuryの戦略と収益分配の管理
  • endBetaModeの実行（アップグレードとベータ期間中の精算修正を恒久的に無効化します）

ベータ期間中

ベータ版には安全のための「補助輪」がいくつかあり、管理者とタイムロックに追加の権限が与えられています。

  • 管理者またはタイムロックは精算ルートを修正できます。そのため、請求プロセスに3日間の異議申し立て期間が加わります

  • タイムロックはRegistry、USD8、Treasury、DefiInsuranceをアップグレードできます

どちらも、ベータ終了とともに廃止されます。

DeFi保険

DeFi保険はすべてのUSD8/sUSD8ユーザーが無料で利用できますが、支払額は請求者の保険スコアやカバープールの規模による上限によって変わります。

支払額が期待に届かない場合に備えて、ユーザーが支払いを受け取るか断るかを自由に選べるプロセスにしています。
