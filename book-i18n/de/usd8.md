## So nutzen Sie USD8 {#how-to-use-usd8}

Für DeFi-Nutzer mit geringer Risikobereitschaft: Halten Sie USD8 oder erzielen Sie damit Rendite – und Sie erhalten kostenlos eine DeFi-Versicherung für eine Reihe von DeFi-Token und -Positionen, USD8 selbst eingeschlossen.

Für Renditesuchende mit hoher Risikobereitschaft: Zahlen Sie in die Cover Pools von USD8 ein. Sie erzielen eine hohe Rendite und sichern damit zugleich die DeFi-Versicherung ab.

## Onchain + Open Source {#onchain--open-sourced}
Das USD8-System besteht aus einem Onchain- und einem Offchain-Teil; der gesamte Code ist Open Source. Der Onchain-Teil folgt gängiger DeFi-Praxis: Sensible Einstellungen laufen über einen Timelock. Der Offchain-Teil rechnet in einer TEE mit Open-Source-Algorithmen, und jeder kann die Ergebnisse überprüfen.

Diese Dokumentation erklärt USD8 in einfachen Worten. Technische Details und den Code finden Sie in unserem [GitHub-Repository](https://github.com/Usd8-fi/usd8-core).
