## Badge „Covered by USD8“ {#covered-by-usd8-badge}

Partner, deren Token durch USD8 abgesichert sind, können dieses Badge auf ihrer Website zeigen. Verlinken Sie es auf https://usd8.fi.

<figure class="brand-asset">

<figcaption>Kleines Badge, dunkel <a href="../assets/brand/covered-by-usd8-dark.svg" download>SVG herunterladen</a></figcaption>
</figure>
<figure class="brand-asset">
<div class="brand-swatch brand-swatch-light"><a class="brand-badge-link" href="https://usd8.fi" target="_blank" rel="noopener"><img src="../assets/brand/covered-by-usd8-light.svg" width="159" height="32" alt="Covered by USD8"></a></div>
<figcaption>Kleines Badge, hell <a href="../assets/brand/covered-by-usd8-light.svg" download>SVG herunterladen</a></figcaption>

Um das kleine Badge einzubinden, fügen Sie diesen Code in Ihre Seite ein:

```html
<a href="https://usd8.fi" target="_blank" rel="noopener">
  <img src="https://usd8.fi/assets/brand/covered-by-usd8-dark.svg"
       alt="Covered by USD8" width="159" height="32">
</a>
```
