## Badge « Covered by USD8 » {#covered-by-usd8-badge}

Les partenaires dont les tokens sont couverts par USD8 peuvent afficher ce badge sur leur site web. Faites-le pointer vers https://usd8.fi.

<figure class="brand-asset brand-asset-dark">

<figcaption>Badge sombre <a href="../assets/brand/covered-by-usd8-dark.svg" download>Télécharger le SVG</a></figcaption>
</figure>
<figure class="brand-asset brand-asset-light">

Pour intégrer le badge, collez ce code dans votre page. Pour la version claire, remplacez le fichier par `covered-by-usd8-light.svg`.

```html
<a href="https://usd8.fi" target="_blank" rel="noopener">
  <img src="https://usd8.fi/assets/brand/covered-by-usd8-dark.svg"
       alt="Covered by USD8" height="32">
</a>
```
