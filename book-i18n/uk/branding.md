## Значок «Covered by USD8» {#covered-by-usd8-badge}

Партнери, чиї токени застраховані USD8, можуть розмістити цей значок на своєму сайті. Зробіть його посиланням на https://usd8.fi.

<figcaption>Темний значок <a href="../assets/brand/covered-by-usd8-dark.svg" download>Завантажити SVG</a></figcaption>

<a class="brand-badge-link" href="https://usd8.fi" target="_blank" rel="noopener"><img src="../assets/brand/covered-by-usd8-light.svg" width="159" height="32" alt="Covered by USD8"></a>
<figcaption>Світлий значок <a href="../assets/brand/covered-by-usd8-light.svg" download>Завантажити SVG</a></figcaption>
</figure>
</div>

Щоб вбудувати значок, вставте цей код на свою сторінку. Для світлої версії замініть файл на `covered-by-usd8-light.svg`.

```html
<a href="https://usd8.fi" target="_blank" rel="noopener">
  <img src="https://usd8.fi/assets/brand/covered-by-usd8-dark.svg"
       alt="Covered by USD8" height="32">
</a>
```
